My Workflow

How I bring ideas to life

1
Research & Plan

Every great project starts with understanding the problem. I spend time researching the target users, defining goals, and mapping out the architecture before writing a single line of code or opening Figma.

2
Design & Prototype

With a clear vision in place, I move into design — creating wireframes and interactive prototypes in Figma. This phase lets stakeholders see and feel the product early, enabling fast feedback loops before development begins.

3
Build & Develop

This is where designs come to life. I write clean, maintainable code with attention to performance and best practices — building features incrementally and testing each component as the project grows.

4
Test & Launch

Before shipping, I rigorously test for bugs, edge cases, and usability issues. Once everything checks out, the project goes live — and I continue to gather feedback for future iterations and improvements.
